# 20260807.以后可能会做的奇思妙想捏

未进入首版实现、未来可能追加的想法清单。按优先级粗略分组。

## 高优先（比较想做的）

- **定时推送早报**：每天定时向指定群推送 /v2/60s 早报（参考 sky-renwu-weibo 的 cron/定时能力），支持多群、多时段配置。
- **热榜对比聚合**：一键对比多个平台（微博/bili/知乎/抖音）同词热度，输出"跨平台热点"。
- **缓存层**：60s 接口部分已有缓存，但插件层可对高频命令（早报/热榜）加 TTL 内存缓存，减少上游压力。
- **命令权限**：给子命令加 `authority` 等级配置（参考 koishi 权限系统），限制谁能用。

## 中优先（看需求）

- **更多渲染模板**：不同风格的 puppeteer 卡片（深色/浅色/简约/花哨），或仿 QQ 卡片样式。
- **图片下载缓存**：早报图/热榜封面图本地缓存，重复请求不重复下载。
- **多 baseUrl 支持**：配置多个 60s 实例（官方/自建/备用），失败自动切换。
- **OpenAPI 生成**：用 60s 官方 OpenAPI 文档自动生成 client.ts，减少手写。
- **歌词播放**：把歌词配上 `h.audio` 播放音乐（需要第三方音源，非 60s 能力）。

## 低优先 / 脑洞

- **摸鱼日报定时**：每天下班前推送 60s摸鱼 今日进度。
- **幸运联动**：一言/运势/黄历组合成"今日塔罗牌"玩法。
- **游戏联动**：早报图直接渲染进 Minecraft 服务器聊天栏（需配合 MC 侧插件）。
- **多语言命令**：除了中文/英文 alias，加日语/粤语命令别名。
- **图标字体渲染**：puppeteer 卡片内置 emoji/图标字体，离线渲染更好看。
- **统计面板**：记录命令调用次数、来源平台、Top 热榜词，Koishi 控制台可视化。
- **webhook 通知**：油价/金价达到阈值时主动通知指定群。

## 明确不做的（除非用户强烈要求）

- 内置 60s API 代理服务（让插件自身变成 API 网关）。
- 支持非 HTTP 传输（RPC/websocket 直连 60s）。
- 绕过 60s 直接抓上游站点数据（维护成本高，违背插件定位）。
