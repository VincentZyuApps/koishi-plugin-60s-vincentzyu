## 配置项（config.ts）

Schema.intersect 分组：

1. **⚙️ 基础** - baseUrl(默认 http://127.0.0.1:64399)、timeout、命令前缀
2. **🎨 渲染** - renderPreset（通用 / QQ 官方 Bot / 自定义）、enableQuote、enableWaitingHint
3. **🤖 QQ官方bot** - keyboard JSON、单选按钮发送方式
4. **🖼️ Puppeteer卡片** - 可选依赖开关、图片格式/宽度/字体
5. **🔍 调试** - verbose 开关

### 输出预设（核心）

```
renderPreset: general | qq-official | custom
customCommandOutput: 每条规范命令 → text | card | image | qq-markdown
```

- `general`：列表→卡片图，单条→文本，天然图片→直接图片；允许回退。
- `qq-official`：QQ 官方 Bot 的列表→原生 Markdown；其他情况按通用预设，允许回退。
- `custom`：逐命令严格执行；不可用时返回错误，不自动降级。
- 命令可使用 `-m text|card|image|qq-markdown` 临时优先尝试。

## API 客户端（client.ts）

- `get<T>(endpoint, params)` → 解析 `{code, message, data}`
- 一个方法对应一个端点，全类型化
- 统一处理 `encoding=json`，错误抛异常

## 渲染三层策略

1. QQ 官方 Bot 预设命中列表 → internal.sendMessage(msg_type:2 markdown+keyboard)
2. 通用或自定义预设命中 card → HTML 模板截图 h.image(base64)
3. 通用预设允许回退到原图或纯文本；自定义预设严格报错
